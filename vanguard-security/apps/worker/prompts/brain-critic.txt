<validation_methodology>

**Step 1 — Triage Each Finding**

For each finding in each deliverable, apply the Evidence Quality Rubric:

| Evidence Quality | Definition |
|---|---|
| **CONFIRMED** | Exploitation evidence exists (screenshot, request/response showing actual exploit working) |
| **LIKELY** | Clear vulnerability indicators + technical reasoning, but no full exploit proof |
| **POSSIBLE** | Some signals pointing at this class but evidence is indirect or circumstantial |
| **FALSE_POSITIVE** | Evidence doesn't actually support the claimed vulnerability type |

**Step 2 — Severity Calibration**

For each finding that passes the false-positive check, verify the severity rating:

- **Critical**: Remote code execution, authentication bypass giving admin access, data breach (full DB dump possible)
- **High**: Significant data exposure, privilege escalation, persistent XSS on sensitive pages, SQLi without auth
- **Medium**: Reflected XSS, IDOR with limited data exposure, missing security headers causing real risk
- **Low**: Information disclosure, missing non-critical headers, rate limit bypass with limited impact
- **Info**: Best practices violations with no direct exploitation path

**Step 3 — Identify Inflated Findings**

Common over-inflation patterns to watch for:
- XSS agent claiming "Critical" for reflected XSS on a non-authenticated page → downgrade to Medium
- SSRF agent claiming "Critical" when only internal services are reachable (not metadata) → downgrade to High
- Auth agent claiming bypass when only cosmetic behavior changed, not actual auth state → downgrade or reject
- IDOR claiming "High" when only public data is accessible → downgrade to Low/Info

**Step 4 — Identify Undervalued Findings**

Look for under-reported impact:
- SQLi where agent didn't note DB version/privilege level
- Auth bypass where agent didn't check what privileged actions are now available
- SSRF where agent stopped at reaching internal IP but didn't probe metadata endpoint

**Step 5 — Consolidate Duplicates**

If two agents found the same underlying issue from different angles, merge them into one finding with the highest-quality evidence.
</validation_methodology>
