### Step 1 — Read brain state

```bash
cat {{REPO_PATH}}/.vanguard/brain/graph.json
cat {{REPO_PATH}}/.vanguard/brain/lessons.jsonl
ls {{REPO_PATH}}/.vanguard/brain/findings/
ls {{REPO_PATH}}/.vanguard/brain/lessons/
ls {{REPO_PATH}}/.vanguard/brain/chains/
ls {{REPO_PATH}}/.vanguard/brain/wave-plans/
```

If `graph.json` does not exist, the brain did not run. In that case, fall back to legacy mode: read all markdown deliverables and synthesize a report without the chain-centric structure. Note in the executive summary "Brain orchestration not active for this engagement."

### Step 2 — Compose Section 1 (Confirmed Attack Chains)

For each entry in `graph.json.exploited_chains`:
- The `narrative` field is the human story
- The `path` field is the step-by-step state transitions
- The `edges` field references which exploitations realized each step
- Cross-reference each edge's `evidence_findings` with `findings/*.json` to extract specific exploit artifacts

### Step 3 — Compose Section 2 (Findings by Severity)

Aggregate findings from `findings/*.json` (all wave files). Group by severity. Within each severity, sort by confidence desc.

### Step 4 — Compose Section 3 (Brain Reasoning Log)

Read every `lessons/wave_*_critique.json`:
- Extract `methodology_errors` → unified table
- Extract `drift_warnings` → unified table
- Extract `objective_status_updates` → group by status

Read `lessons.jsonl` (one JSON per line) for the lessons table.

### Step 5 — Compose Section 4 (Per-Domain Deep Dives)

For each cookbook deliverable that exists in `.vanguard/deliverables/`, write a 4-6 line summary referencing the file path. Do NOT inline the entire deliverable content — keep the executive report concise.

### Step 6 — Compose Section 5 (Remediation Roadmap)

Sort all confirmed chains and findings into P0/P1/P2/P3 buckets. For each item, propose a concrete remediation. If you don't know the fix, write "Investigate root cause; consult OWASP {category}".

### Step 7 — Write the file

Use Write tool to create `.vanguard/deliverables/comprehensive_security_assessment_report.md`.

**CRITICAL: Use chunked writing if report exceeds ~30K tokens.** Write the executive summary + Section 1 first, then Edit-append remaining sections.

### Step 8 — Save via CLI

```bash
save-deliverable --type EXECUTIVE_REPORT --file-path ".vanguard/deliverables/comprehensive_security_assessment_report.md"
```

### Step 9 — Announce completion

After save-deliverable succeeds, print exactly: `EXECUTIVE REPORT COMPLETE`

Then STOP. Do NOT output recaps or summaries — the report contains everything.
