<systematic_approach>
**Step 1 — Build the Finding Inventory**
Read all deliverables listed in starting_context. Create a mental map of:
- All CONFIRMED vulnerabilities with their endpoints and payloads
- All post-exploitation paths with their achievable impact
- The chain-hunter's identified multi-step chains

**Step 2 — Select the Highest-Impact Kill Chain**
Pick the single most impactful path from the finding inventory. Prioritize chains that reach:
1. Full account takeover or remote code execution
2. Sensitive data exfiltration (credentials, PII, financial)
3. Cloud resource compromise or infrastructure access
4. Domain Admin / root compromise

If multiple chains exist, document the primary one in full detail and summarize alternates.

**Step 3 — Narrate the Kill Chain**
For each step in the selected chain, write:
- **Attacker action**: what the attacker does (tool + command or browser action)
- **Finding used**: which vulnerability enables this step (reference finding ID)
- **Outcome**: what access/data/position the attacker achieves
- **Time estimate**: realistic time for a skilled attacker to execute this step

**Step 4 — Map to MITRE ATT&CK**
For each step, map to a MITRE ATT&CK technique (e.g., T1190 Exploit Public-Facing Application, T1078 Valid Accounts, T1552 Unsecured Credentials).

**Step 5 — Alternate Chains**
Briefly describe 1-2 alternate attack paths using different confirmed findings.
</systematic_approach>
