<scope>
Focus on mobile-specific attack surfaces:
- **Android**: APK manifest analysis (exported components, permissions, deep links), insecure data storage (SharedPreferences, SQLite, external storage), network security config, WebView vulnerabilities
- **iOS**: IPA analysis (Info.plist, URL schemes, entitlements), keychain misuse, insecure NSUserDefaults, ATS (App Transport Security) bypass, URL scheme hijacking
- **Both**: Certificate pinning implementation, hardcoded API keys/secrets, OAuth/JWT handling in mobile context, debug mode indicators, rooted/jailbroken device detection bypass
- **PWA/Web**: Service worker caching of sensitive data, push notification permission abuse, offline storage (IndexedDB, localStorage) of credentials
</scope>

<systematic_approach>
**Step 1 — App Discovery**
For each mobile app in the target profile:
```bash
# If Android (APK available):
# Download from store URL or find via recon
# apktool d app.apk -o {{REPO_PATH}}/.vanguard/scratchpad/apk_decompiled/ 2>&1 | tail -5

# Search repo for bundled mobile artifacts
find {{REPO_PATH}} -maxdepth 8 \( -name "*.apk" -o -name "*.ipa" -o -name "*.aab" \) 2>/dev/null | head -5

# Check if app links/deep links are defined in the web app
grep -rn "assetlinks.json\|apple-app-site-association\|applinks\|universallink" \
  {{REPO_PATH}} 2>/dev/null | grep -v ".git\|node_modules" | head -20
```

**Step 2 — Android Manifest Analysis** (if APK/decompiled source available)
```bash
# Check for exported components without permission protection
grep -rn 'android:exported="true"\|android:exported=true' \
  {{REPO_PATH}}/.vanguard/scratchpad/apk_decompiled/ 2>/dev/null | head -20

# Find deep link schemes
grep -rn 'android:scheme\|intent-filter\|data android:host' \
  {{REPO_PATH}}/.vanguard/scratchpad/apk_decompiled/ 2>/dev/null | head -20

# Dangerous permissions
grep -rn 'READ_CONTACTS\|WRITE_EXTERNAL_STORAGE\|ACCESS_FINE_LOCATION\|READ_SMS\|CAMERA' \
  {{REPO_PATH}}/.vanguard/scratchpad/apk_decompiled/ 2>/dev/null | head -10
```

**Step 3 — Hardcoded Secrets in Mobile Source**
```bash
# Search for hardcoded API keys, tokens, secrets in mobile source
grep -rn 'api_key\|apiKey\|secret\|token\|password\|AUTH_TOKEN\|CLIENT_SECRET' \
  {{REPO_PATH}} --include="*.java" --include="*.kt" --include="*.swift" --include="*.m" \
  --include="*.dart" --include="*.js" 2>/dev/null | grep -v ".git\|test\|mock" | head -20

# Check for AWS/Firebase/GCP keys in mobile code
grep -rn 'AKIA\|AIza\|firebase\|supabase' \
  {{REPO_PATH}} --include="*.java" --include="*.kt" --include="*.swift" \
  --include="*.dart" --include="*.js" 2>/dev/null | grep -v ".git\|node_modules" | head -10
```

**Step 4 — Network Security Configuration**
```bash
# Android Network Security Config
find {{REPO_PATH}} -name "network_security_config.xml" 2>/dev/null | xargs cat 2>/dev/null | head -30

# Check for cleartext traffic allowance
grep -rn 'cleartextTrafficPermitted\|android:usesCleartextTraffic\|NSAllowsArbitraryLoads' \
  {{REPO_PATH}} 2>/dev/null | grep -v ".git" | head -10

# iOS ATS exceptions
grep -rn 'NSAppTransportSecurity\|NSExceptionDomains\|NSAllowsArbitraryLoads' \
  {{REPO_PATH}} --include="*.plist" --include="*.xml" 2>/dev/null | head -10
```

**Step 5 — Deep Link / Universal Link Testing**
```bash
# Test well-known app association files
curl -s --max-time 5 "{{WEB_URL}}/.well-known/assetlinks.json" 2>/dev/null | head -30
curl -s --max-time 5 "{{WEB_URL}}/.well-known/apple-app-site-association" 2>/dev/null | head -30

# Test deep link endpoints directly
grep -rn 'scheme.*://\|openURL\|handleOpenURL\|continueUserActivity' \
  {{REPO_PATH}} 2>/dev/null | grep -v ".git\|node_modules\|test" | head -20
```

**Step 6 — WebView Analysis**
```bash
# Check for dangerous WebView configurations
grep -rn 'setJavaScriptEnabled(true)\|addJavascriptInterface\|setAllowFileAccess\|WKUserContentController' \
  {{REPO_PATH}} --include="*.java" --include="*.kt" --include="*.swift" 2>/dev/null \
  | grep -v ".git" | head -20
```
</systematic_approach>
