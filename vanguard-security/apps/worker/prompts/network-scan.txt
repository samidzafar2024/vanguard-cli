<systematic_approach>
**Step 1 — DNS Resolution**
Resolve the target to IP(s):
```bash
host {{WEB_URL}} 2>/dev/null | head -5
dig +short $(echo "{{WEB_URL}}" | sed 's|https\?://||' | cut -d/ -f1) 2>/dev/null | head -5
```

**Step 2 — Port Scan (TCP)**
Run nmap with service detection. Use --max-rate to respect WAF rate limits:
```bash
TARGET=$(echo "{{WEB_URL}}" | sed 's|https\?://||' | cut -d/ -f1)

# Top 1000 ports with service/version detection
nmap -sV -sC --open --max-rate 100 -oN {{REPO_PATH}}/.vanguard/scratchpad/nmap_tcp.txt \
  -T3 "$TARGET" 2>&1 | tail -50

cat {{REPO_PATH}}/.vanguard/scratchpad/nmap_tcp.txt 2>/dev/null | head -80
```

**Step 3 — Common Admin & DB Ports**
Target high-value ports specifically:
```bash
nmap -sV --open -p 22,23,3306,5432,6379,27017,9200,9300,11211,8080,8443,8888,9000,3000,5000 \
  --max-rate 50 -oN {{REPO_PATH}}/.vanguard/scratchpad/nmap_admin.txt \
  "$TARGET" 2>&1 | tail -30
```

**Step 4 — Banner Grabbing**
For each discovered open port, grab the service banner:
```bash
# For each open non-web port found in Step 2/3:
nc -w 3 "$TARGET" PORT 2>/dev/null | head -5
```

**Step 5 — CVE Correlation**
For each service version discovered, search for known CVEs:
```bash
# Use nmap vuln scripts for quick CVE checks
nmap --script vuln -p OPEN_PORTS --max-rate 30 \
  -oN {{REPO_PATH}}/.vanguard/scratchpad/nmap_vuln.txt \
  "$TARGET" 2>&1 | grep -i "CVE\|VULNERABLE\|state: VULNERABLE" | head -20
```

**Step 6 — Subdomain Port Sweep**
For key subdomains from OSINT deliverable (top 5 by priority):
```bash
# Quick scan of priority subdomains
for subdomain in SUBDOMAIN1 SUBDOMAIN2; do
  echo "=== $subdomain ==="
  nmap -F --open --max-rate 50 -T3 "$subdomain" 2>&1 | grep "open\|filtered" | head -10
done
```
</systematic_approach>
