<systematic_approach>
**Step 1 — GitHub Org Discovery**
```bash
# Discover org repos via GitHub API
ORG_NAME="$(cat .vanguard/deliverables/osint_recon_deliverable.md | grep -i 'organisation name' | head -1 | sed 's/.*: //')"
curl -s "https://api.github.com/orgs/${ORG_NAME}/repos?per_page=30&type=public" \
  ${GITHUB_TOKEN:+-H "Authorization: token $GITHUB_TOKEN"} 2>/dev/null | \
  python3 -c "import json,sys; repos=json.load(sys.stdin); [print(r['full_name'], r.get('updated_at','')) for r in repos if isinstance(repos, list)]" 2>/dev/null | head -30
```

**Step 2 — TruffleHog Scan on Local Repo**
```bash
# Scan the local repository for secrets (TruffleHog OSS)
if command -v trufflehog >/dev/null 2>&1; then
  trufflehog filesystem {{REPO_PATH}} --json --no-update 2>/dev/null | \
    python3 -c "import json,sys; [print(json.dumps(l, indent=2)) for line in sys.stdin for l in [json.loads(line)] if l.get('SourceMetadata')]" 2>/dev/null | head -200
else
  echo "TruffleHog not installed — falling back to grep-based scan"
fi
```

**Step 3 — Grep-Based Secret Patterns (Fallback)**
```bash
# Search for common secret patterns in the local repo
cd {{REPO_PATH}} && grep -r --include="*.{js,ts,py,go,env,yaml,yml,json,toml,rb,php,sh,conf,cfg,ini}" \
  -E "(api[_-]?key|secret[_-]?key|access[_-]?token|auth[_-]?token|client[_-]?secret|password\s*=|passwd\s*=|AKIA[0-9A-Z]{16}|sk-[a-zA-Z0-9]{48}|ghp_[a-zA-Z0-9]{36}|xox[baprs]-)" \
  --exclude-dir=node_modules --exclude-dir=.git -l 2>/dev/null | head -30
```

**Step 4 — Git History Secret Scan**
```bash
# Scan git log for secrets that may have been committed then deleted
cd {{REPO_PATH}} && git log --oneline --all 2>/dev/null | head -5
git log -p --all --since="2 years ago" -- "*.env" "*.key" "*.pem" "*secret*" "*credential*" 2>/dev/null | \
  grep -E "^[+-].*?(api_key|secret|password|token|AKIA)" | head -50
```

**Step 5 — GitHub Search API for Public Secrets**
```bash
# Search GitHub for org-related exposed secrets (public code search)
TARGET_DOMAIN=$(grep -i 'primary domain' .vanguard/deliverables/target_profile_deliverable.md 2>/dev/null | head -1 | sed 's/.*: //')
curl -s "https://api.github.com/search/code?q=${TARGET_DOMAIN}+password+OR+secret+OR+api_key&per_page=10" \
  ${GITHUB_TOKEN:+-H "Authorization: token $GITHUB_TOKEN"} 2>/dev/null | \
  python3 -c "import json,sys; d=json.load(sys.stdin); [print(i['repository']['full_name'], i['path']) for i in d.get('items',[])]" 2>/dev/null | head -20
```

**Step 6 — Public Gist Search**
```bash
# Check for org-related Gists (developers sharing config snippets)
for user in $(grep -A5 'Employee' .vanguard/deliverables/osint_recon_deliverable.md 2>/dev/null | grep -oE '@[a-zA-Z0-9_-]+' | tr -d '@' | head -5); do
  curl -s "https://api.github.com/users/${user}/gists?per_page=10" \
    ${GITHUB_TOKEN:+-H "Authorization: token $GITHUB_TOKEN"} 2>/dev/null | \
    python3 -c "import json,sys; [print(g['html_url'], g.get('description','')) for g in json.load(sys.stdin) if isinstance(json.load(sys.stdin) if False else json.loads('[]'), list)]" 2>/dev/null | head -10
done
```

**Step 7 — Classify and Validate Findings**
For each secret candidate found, classify:
- **Confirmed** — matches known secret pattern (AKIA..., sk-..., ghp_..., etc.)
- **Likely** — credential-shaped string near auth-related variable name
- **Uncertain** — placeholder/example value (e.g., `your-api-key-here`)

For confirmed findings, note the service type (AWS, OpenAI, GitHub, Stripe, etc.) and whether the secret is current or potentially revoked.
</systematic_approach>
